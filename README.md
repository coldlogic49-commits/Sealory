Offer Telegram bot (Node.js / grammY)
1. Установите Node.js 20+.
2. npm install
3. Укажите переменную окружения BOT_TOKEN.
4. npm start
5. В BotFather включите Inline Mode через /setinline.
6. Администратор Telegram ID 8882210622 должен отправить боту /start.
7. Для сохранения данных между перезапусками обеспечьте постоянное хранение offer-data.json.

Команды: /start, /help, /offer, /recipient @username, /cancel.

Бот не выполняет платежи, не резервирует Stars и не подтверждает передачу NFT автоматически. Ссылки на NFT дают предпросмотр Telegram, если он доступен. Проверка подарка активации и передачи NFT — вручную администратором.
