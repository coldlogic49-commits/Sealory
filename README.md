# SealoryNFT Telegram Bot

Telegram-бот на Node.js + grammY. Меню, каталог 124 NFT, поиск, цены выкупа, СБП/Stars и заявки.

## Запуск на FadeHost
1. Загрузите **содержимое** этого архива в корень GitHub-репозитория `Sealory` (не папку `sealory_bot` целиком).
2. В настройках FadeHost укажите переменную окружения `BOT_TOKEN` — токен из @BotFather. **Не публикуйте токен в GitHub.**
3. Runtime: Node.js 18+; команда запуска: `npm start` (если потребуется).
4. Запустите Deploy.

Дополнительно можно настроить `SUPPORT_USERNAME`, `CHANNEL_USERNAME`, `ADMIN_ID` в переменных окружения.

## Важно
- Проверка поступления NFT не подключена. Бот не подтверждает получение без внешней интеграции.
- История и заявки хранятся **только в памяти** и пропадают после перезапуска. Для реальной эксплуатации нужна база данных.
- Цены взяты из предоставленного списка, курс Stars — 100 ⭐ за 150 ₽. Для дробных значений округление вниз.
- Разделы продажи Stars и Gram пока направляют в поддержку.
- Необходимо обеспечить прозрачные условия передачи подарков и выплаты до использования с реальными клиентами.
